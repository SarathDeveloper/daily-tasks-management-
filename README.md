# Dayflow

A personal daily OS for tasks, focus sessions, and spending — built with React + Vite. Plan your day on the Today view, run Pomodoro sessions in the Focus Room, track income/expenses with budgets, debts, and savings goals, and keep everything local to your device.

It ships two ways from the same codebase:

- **Web / PWA** — installable from Chrome, offline capable.
- **Android APK** — a Capacitor shell with real scheduled notifications that fire with the app closed, plus optional Google Drive backup.

All data lives in `localStorage`; there is no backend. Cloud backup is optional and writes a single JSON snapshot to a hidden folder in your own Google Drive.

## Features

**Tasks**
- Today and Timeline views with a date bar for navigation
- Priorities (low / medium / high / urgent), subtasks, tags, and estimated minutes
- Recurrence: none, daily, weekdays, weekly, monthly, or custom interval
- Per-task reminders with sound selection and snooze
- Quick-add from the floating action button

**Focus Room**
- Pomodoro / short break / long break modes
- Ambient sound option and bell on completion
- Mark a task complete directly from the session

**Categories**
- Custom categories with color and Lucide icon
- Default starter categories included

**Stats**
- Completion and productivity breakdowns across your tasks

**Finance**
- Money Ledger with multiple accounts: cash wallet, savings, current, and other
- Opening balances plus automatically derived account balances (never stored separately)
- Income and expense entries routed to a specific account, with payment method (cash / GPay / PhonePe / bank / card / other)
- Transfers between accounts (including ATM withdrawals with an optional fee), never counted as income or expense
- Account detail screens with credited / debited / transfer totals and running balances
- Ledger history with search, type / account / category / payment / date filters, and day / week / month / year summaries
- Monthly income, expense, net-flow, category and source breakdowns with month-over-month comparison
- Archived accounts keep their history; a migration tool assigns pre-ledger entries
- Recurring transactions (none / daily / weekly / monthly)
- Monthly budgets and per-category budgets
- Debts: track money lent or owed, with paid status
- Savings goals per month
- Bill templates with auto-materialized monthly payments, optionally paid from a chosen account
- Budget alerts at 80% (warning) and 100% (critical)

**App**
- Light / dark theme
- Browser notifications with quiet hours
- Sound effects and speech options
- One device profile for tasks, money, and diary. Optional Google Drive merge keeps the desktop site and the phone on the same file
- Undo toast for deletes, JSON export / import, reset to sample data

**Android app**
- Native scheduled reminders (AlarmManager) that survive the app being closed and the phone rebooting
- Per-sound notification channels (chime / bell / digital / gentle / silent) generated from `scripts/generate-notification-sounds.mjs`
- Notification tap opens the right task; in-app banner mirrors the native alert
- Hardware back button closes modals before leaving the app
- Dark splash screen and status bar that follows the theme
- Reminder reliability diagnostics (notification permission, exact alarms, OEM battery tips)
- Optional Google sign-in with Drive `appDataFolder` backup and record-level merge

## Tech Stack

- [React 19](https://react.dev/) with TypeScript
- [Vite 6](https://vitejs.dev/) for dev server and build
- [Tailwind CSS 4](https://tailwindcss.com/) via `@tailwindcss/vite`
- [Motion](https://motion.dev/) for animations
- [Lucide React](https://lucide.dev/) for icons
- [Capacitor 8](https://capacitorjs.com/) + `@capacitor/local-notifications`, `app`, `splash-screen`, `status-bar`, `@capawesome/capacitor-google-sign-in`
- [Google Drive API v3](https://developers.google.com/workspace/drive/api/guides/appdata) via plain `fetch` (no SDK)
- `localStorage` for all persistence; no server

## Android app (sideload, no Play Store)

The `android/` project is generated by Capacitor and committed, so building the
APK needs no IDE.

One-time prerequisites on this machine:

- Node 22+
- A JDK 21 (Capacitor's notification plugin compiles with Java 21). The path is
  pinned in `android/gradle.properties` via `org.gradle.java.home`. Change that
  line if your JDK lives somewhere else.
- The Android SDK, wired through `android/local.properties` (git-ignored).

Build and install:

```bash
npm run build:android     # vite build --mode capacitor && cap sync android
npm run apk:debug         # android/app/build/outputs/apk/debug/app-debug.apk
npm run apk:release       # signed APK using android/keystore.properties
npm run apk:install       # adb install -r (device must be connected)
```

Without a cable, copy `android/app/build/outputs/apk/release/app-release.apk`
to the phone and allow "Install unknown apps" for the file manager.

Signing: `dailytasks.keystore` (repo root) plus `android/keystore.properties`
hold the release key. Both are git-ignored. **Keep them** — Android will refuse
to install an update signed with a different key. The keystore SHA-1 is
`60:BF:C7:3D:F4:C3:BB:E2:16:56:BE:4B:A3:19:C3:BE:B0:46:DA:BE`, which is what
the Google Cloud Android OAuth client must be registered with.

Notification sounds are generated once into
`android/app/src/main/res/raw/*.wav`. Re-run
`node scripts/generate-notification-sounds.mjs` if you want to tweak them.

Each task's chime choice maps to its own notification channel
(`reminders_chime`, `reminders_bell`, `reminders_digital`, `reminders_gentle`,
plus `reminders_silent` when in-app sound is off). Two Android constraints to be
aware of:

- Channel settings are immutable once created, so changing a task's sound takes
  effect on its next scheduled reminder, and Android remembers per-channel sound
  overrides the user made in system settings.
- A notification channel cannot run text-to-speech, so the `voice` option falls
  back to the chime channel on Android. The in-app banner still shows the task.

Bumping a release: raise `versionCode`/`versionName` in
`android/app/build.gradle`, rebuild, and install over the previous APK.

## Environment

See [`.env.example`](.env.example).

| Variable | Required | Purpose |
| --- | --- | --- |
| `VITE_GOOGLE_CLIENT_ID` | No | Web OAuth client id from Google Cloud Console. Needed only for Google Drive backup |

Everything else works without environment variables. To enable cloud backup:

1. Google Cloud Console -> enable **Google Drive API**.
2. OAuth consent screen -> External -> add your Gmail as a test user.
3. Create an OAuth client of type **Web application**; copy the client id into
   `.env` and into the host's `VITE_GOOGLE_CLIENT_ID` build variable. On that
   same Web client, add every origin you sign in from — `http://localhost:3000`
   and the deployed site, such as `https://your-app.vercel.app` — to **both**
   Authorized JavaScript origins and Authorized redirect URIs. Use the origin
   only, with no path and no trailing slash. That is the exact `redirect_uri`
   the app sends (`window.location.origin`). A `redirect_uri_mismatch` error
   means that origin is missing. Copy it from the Google error page’s **error
   details**, not from the `accounts.google.com` address bar. A trailing slash
   is a different URI and will still be rejected. Preview URLs
   (`*-git-*.vercel.app`) are separate origins. The Android client cannot
   be used for the website.
4. Create an OAuth client of type **Android** with package
   `com.dayflow.dailytasks` and the keystore SHA-1 above.
5. Rebuild. The only scope requested is
   `https://www.googleapis.com/auth/drive.appdata` (non-sensitive: access to a
   hidden per-app folder only).

## Data and Privacy

- All data is stored in `localStorage` on this device, under one set of keys. There is no local account.
- Desktop and phone stay in sync by connecting the same Google account. Both write `daily-tasks-sync.json` in Drive's hidden `appDataFolder`. Connect and Sync now merge; Restore replaces this device and drops edits that were never uploaded.
- Clearing app/browser storage erases all tasks and finance data. Use Export JSON or Google Drive backup to keep a copy.
- Google Drive backup is optional and off until you connect. The app cannot see any other file in your Drive.
- The Drive access token is cached on the device with a 55-minute expiry so sync keeps working across launches without prompting. Disconnecting clears it. Sync is last-write-wins per record, with deletes tracked for 90 days.
